# 01 - irrigacao

# Módulo higrômetro HW-103
# comparador LM393 e sonda resistiva
# Princípio de medição: Resistivo, por condução elétrica entre duas hastes inseridas no solo. Quanto maior a umidade, menor a resistência elétrica.
# Alimentação: 3,3 V a 5,0 V DC.
# Saídas: Analógica (A0) e digital (D0). Na saída digital, o limiar de acionamento é ajustado por um potenciômetro na placa.
# Indicadores: LED de alimentação e LED de estado da saída digital.
# Limitação prática: Eletrodos resistivos sofrem oxidação/eletrólise com o tempo quando ficam energizados continuamente na terra, sendo indicados sobretudo para prototipagem e testes.
